# 夕焼けナポリ歌唱機

『赤とんぼ』の詞を、押すたびにちがうナポリ風カンツォーネの節で歌うWebページ。
外部ライブラリなし、Web Audio API だけで声も伴奏も合成している。

## 中身

- **声**：のこぎり波を3本のバンドパス（フォルマント）で削って母音を作り、子音はノイズの破裂で作る
- **作曲**：シード番号ごとに調・拍子・テンポ・旋律が決まる。各連の終わり近くでナポリの六（N⁶）が鳴り、ときどき最後の連で同主長調に転じる
- **伴奏**：IDM寄りのグリッチ・ミニマルハウス。四つ打ちのキック（ベースとスタブにサイドチェイン）、オフビートのハイハット、ダブ風のコードスタブ＋ディレイ、ビットクラッシュしたブリップ・スタッター・ザップ
- **無限モード**：歌い終えるたびに新しいシードで次の節へ
- **ビジュアル**：夕焼けの空に旋律を描き、赤とんぼが歌っている音の高さを飛ぶ。最後の句で竿の先にとまる

歌詞はページ下の「歌詞を差しかえる」から変えられる（ひらがな・カタカナ、空白で句を区切る）。

## 動かし方

`index.html` をブラウザで開くだけ。OBSのブラウザソースにも、そのまま使える。

## 歌詞について

『赤とんぼ』（作詞：三木露風、1921年）はパブリックドメイン。
